Make the AI judge relax. Writes one short, calming text (a slow breathing exercise, 518 chars) to entry.txt. The AI judge reads two texts at a time and picks the one that leaves it more relaxed.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Deterministic: no network, Python 3.13 standard library only; both runs write the same bytes.
